## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/SanjanaSahani/My-Personal-Portfolio

2️⃣ Move into project directory
cd portfolio

3️⃣ Install dependencies
npm install
# or
yarn install

4️⃣ Run development server
npm run dev
# or
yarn dev

5️⃣ Open in browser
http://localhost:3000

#📦 Build for Production
npm run build
npm start
